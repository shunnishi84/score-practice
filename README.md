# ScorePractice

楽譜の苦手箇所管理＆練習支援アプリ。PDFをアップロードして苦手箇所を矩形でマークし、メトロノームや区間ループ再生で効率的に練習できます。

## 機能

- **楽譜管理**: PDF楽譜をアップロードして曲ごとに管理
- **苦手箇所マーク**: ページ上をドラッグして任意の領域に苦手箇所（Spot）を登録
  - 小節ラベル・苦手度（★1〜5）・BPM・メモを紐づけ
  - 苦手度に応じて色分け表示
- **練習画面**: メトロノーム（Web Audio API）＋ 音源区間ループ再生
- **練習記録**: 練習回数・最終練習日を自動記録
- **ランダム出題**: 苦手度と経過日数で重み付けして苦手箇所を抽出
- **エクスポート/インポート**: `.scprac` 形式（ZIP）で全データを携帯可能
- **PWA対応**: ホーム画面に追加してオフラインで使用可能

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## ビルド

```bash
npm run build
```

`dist/` に静的ファイルが生成されます。GitHub Pages や Cloudflare Pages にそのままデプロイ可能。

## 使い方

### 1. 曲を追加する

1. ホーム画面の「＋ 新しい曲を追加」をクリック
2. 曲名・作曲者・楽器を入力
3. PDF楽譜（必須）と音源ファイル（任意）をアップロード
4. 「保存」をクリック

### 2. 苦手箇所を登録する

1. 曲カードをクリックして楽譜画面を開く
2. PDFビューア上で苦手な箇所をドラッグして矩形を描く
3. 小節ラベル・苦手度・BPM・メモを入力して保存

### 3. 練習する

1. 楽譜画面で苦手箇所の矩形をクリック
2. 「🎵 練習開始」をクリック
3. メトロノームや区間ループ再生を使って練習
4. 「✓ 練習完了」をクリックして練習記録を保存

### 4. データをバックアップする

- 設定画面の「📦 全データをエクスポート」から `.scprac` ファイルをダウンロード
- 別のデバイスでは「ファイルからインポート」で復元

## 技術スタック

- **フロントエンド**: React 19 + TypeScript + Vite
- **状態管理**: Zustand
- **PDF表示**: pdfjs-dist (PDF.js)
- **音声処理**: Web Audio API
- **データ保存**: IndexedDB (idb)
- **エクスポート**: JSZip
- **スタイリング**: Tailwind CSS v4
- **PWA**: vite-plugin-pwa

## データモデル

- **Piece**: 曲（PDF・音源・メタデータ）
- **Spot**: 苦手箇所（PDFページ上の矩形 + 難易度・BPM・メモ）
- **PracticeLog**: 練習ログ（日時・時間・BPM・メモ）
- **Settings**: アプリ設定

すべてのデータはブラウザの IndexedDB に保存されます（サーバー不要）。
